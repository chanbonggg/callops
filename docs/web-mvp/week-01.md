# 1주차 · 자동 수집의 입력과 완료 조건

[전체 계획](README.md) · [다음 주](week-02.md)

**종료 목표** · WAV·M4A·MP3·AMR의 지원 목표와 검증 범위를 정하고, 갤럭시 테스트 녹음 한 건을 완전하게 수신·분류한다. RAG 개발에 사용할 첫 평가 세트를 준비한다.

## 작업

- [x] 기존 `scripts/manage.py ingest`와 `src/callops/calls/service.py`에서 파일 판독, SHA-256 검증, 격리 복사와 분류 경계를 확인한다. 현재 서버 검증 경로는 PCM WAV다.
- [x] 업무 승인 전에 상대 이름과 확인한 통화 시각을 입력하고 상대·날짜로 검색한다. 시각은 한국 시간으로 입력하고 DB에는 시간대가 있는 값으로 저장한다. 사적·만료 정리 시 통화 정보도 지운다.
- [ ] 실제 업무 음성 없이 갤럭시에서 가상 대화를 녹음한다. 파일 형식·길이, 파일명에서 확인 가능한 정보, 통화 시각과 상대 식별의 출처를 기록한다. 자동으로 판단할 수 없는 값은 웹에서 입력·보정하도록 정한다.
- [ ] 기획서의 FolderSync·SFTP를 테스트 폴더 하나로 검토한다. 휴대전화 → 서버 단방향, 신규 파일만 대상으로 설정한다. 기기 연결은 범위를 확인한 뒤 실행한다.
- [ ] 중단 파일과 완료 파일을 구분할 수 있는 신호를 정하고 확인한다. 수신 도구의 완료 신호나 검증한 임시 파일 → 최종 파일 전환을 사용한다. 완료가 확인된 파일의 해시만 기존 수집 API에 전달한다.
- [ ] WAV·M4A·MP3·AMR을 지원 목표로 공통 수집·검증 경로를 설계한다. 수신 시 실제 컨테이너·음성 스트림과 크기·길이 상한을 확인하고, 업무 승인 후 워커에서 디코딩한다. 갤럭시 샘플은 첫 실제 입력의 확인에 사용한다.
- [ ] 형식별 합성 샘플로 수신·분류, 확장자와 내용 불일치, 손상·부분 파일, 중복·삭제를 시험한다. 정상 형식은 실제 코덱과 실행 환경을 기록하고, 승인 후 전사까지 통과한 조합을 지원 완료로 표시한다.
- [x] [가상 전사 10건과 개발 질문 20개](../../tests/fixtures/rag-development.json)를 만든다. 질문별 상대·기간, 기대 답변, 근거 ID·타임스탬프, 답변 보류 여부를 기록한다. [질문 유형 배분](week-02.md#평가-세트-확정)

## 통과 기준

| 시험 | 기대 결과 |
| --- | --- |
| 완료 전 파일, 전송 중단 후 재연결 | 완료 전에는 목록·작업 큐에 반영되지 않고, 재전송 완료 후 한 건만 표시된다. |
| 동일 녹음과 이름을 바꾼 복사본 | 업무 승인 뒤에도 녹음·STT 작업이 각각 한 건이다. |
| 사적 분류와 서버 사본 삭제 | AI 호출 0회, 서버 관리 사본 청소, 갤럭시 원본 보존. |
| 지원하지 않는 형식 | 실패 사유가 보이며 승인 작업이 생성되지 않는다. |
| 지원 목표 형식의 위장·손상 파일 | 파일명만으로 승인 작업을 생성하지 않는다. 실제 내용 검증 실패를 구분한다. |

## 형식별 검증표

| 지원 목표 | 실제 컨테이너·코덱 | 수신·분류 | 승인 후 디코딩·전사 | 원음·구간 재생 |
| --- | --- | --- | --- | --- |
| WAV | PCM WAV만 기존 검증 | 합성 PCM WAV 검증됨 | 미검증 | 기존 PCM WAV 조회 외 실제 브라우저 미검증 |
| M4A | 샘플 확인 필요 | 미구현 | 서버 연계 미검증 | 미검증 |
| MP3 | 샘플 확인 필요 | 미구현 | 서버 연계 미검증 | 미검증 |
| AMR | 샘플 확인 필요 | 미구현 | 서버 연계 미검증 | 미검증 |

확장자와 파일 내부 형식을 함께 확인한다. 실제 디코더가 거부하는 코덱은 지원 불가 상태로 표시한다. 별도 재생용 사본이 필요하면 업무 승인 후 생성하고 기존 사본 추적·삭제 경계에 포함한다. [faster-whisper의 PyAV 디코딩 안내](https://github.com/SYSTRAN/faster-whisper#requirements)

휴대전화 연결 전에는 가짜 수신 폴더로 완료·중복·삭제 경로를 검증한다. 실제 전송 결과는 별도로 남긴다. [서버 수집 구현](../p2-p3-server.md#수집분류)
