# 3주차 · Qwen 요약과 통화 상세 웹

[이전 주](week-02.md) · [전체 계획](README.md) · [다음 주](week-04.md)

**종료 목표** · 승인된 녹음의 수신부터 전사·요약 표시까지 브라우저에서 확인한다. 이후 RAG와 후보 검토가 사용할 통화·전사 연결을 확정한다.

## 작업

- [ ] 큐의 분석 작업에 `ai-worker/app/analyzer.py`의 Qwen3 8B를 연결한다. 서버에 수락된 전사와 확인 가능한 통화 기준 시각을 입력으로 사용한다.
- [ ] 요약·일정·할 일 후보의 스키마와 근거 ID를 검사한다. 전사에 없는 ID, 시각 범위를 벗어난 근거, 필수 필드 누락은 오류로 다룬다. 날짜나 역할이 불확실한 후보는 확인 필요로 남긴다.
- [ ] 장문에서 전사 구간을 버리고 전체 완료로 표시하는 경로를 막는다. 지원 길이를 먼저 정하고, 상한 초과는 상태로 구분한다. 분할을 적용하면 다른 조각에 걸친 정정·취소와 전체 처리 범위를 검증한다.
- [x] 목록에 상대·통화 일시·처리 상태를 표시하고 업무 승인 전에 상대·시각을 수동 보정한다. 상대·한국 날짜로 검색할 수 있다. 처리 기준이 바뀌는 것을 막기 위해 승인 이후 정보 편집은 잠근다.
- [x] 상세에서 합성 구간별 전사를 조회하고, 전사 버전·구간에 고정된 출처 링크와 원음 시간 링크를 제공한다. 실제 브라우저의 구간 재생은 후속 검증한다.
- [ ] 상세에서 모델 요약을 조회하고 실제 전사·원음으로 검증한다.
- [ ] 분석만 실패하면 저장된 전사본으로 해당 단계부터 재시도한다. 목록과 상세는 기존 로그인과 조회 권한을 적용하고, 휴대전화 브라우저에서도 읽고 재생할 수 있게 한다.

## 통과 기준

- 가상 녹음 1건을 업무 지정하면 실제 STT와 분석을 거쳐 요약이 웹에 표시된다. 미분류·사적 음성의 AI 호출은 0회다.
- 정답 전사로 Qwen을 평가한 결과와 실제 STT 전사를 입력한 결과를 분리한다. 날짜·시간·주체 오류를 STT와 분석 중 어느 단계에서 만들었는지 기록한다.
- 분석 실패 후 재시도는 STT를 다시 실행하지 않는다. 비로그인 접근과 삭제·만료된 녹음의 상세·음성 조회가 차단된다.
