# 4주차 · 통화 RAG와 후보 검토

[이전 주](week-03.md) · [전체 계획](README.md) · [다음 주](week-05.md)

**종료 목표** · 질문에 답하고 답변의 근거 발화를 재생한다. 일정·할 일 후보를 화면에서 확인하고 수정·승인할 수 있게 한다.

## 작업

- [x] 개발용 가상 통화 10건·질문 20개의 정답과 근거 ID를 준비한다. 상대·기간 안에 근거가 포함되는지 하네스에서 검사한다. [개발 자료](../../tests/fixtures/rag-development.json)
- [x] 전사 artifact ID와 구간 ID에 고정된 출처 조회 경로를 구현한다. 사적·삭제·만료된 전사와 다른 통화의 전사는 같은 링크로 조회할 수 없다.
- [x] 합성 전사 키워드 검색을 구현한다. 업무 승인·보관 상태·거래처·한국 날짜 범위에 맞는 전사 구간을 찾아 최대 5개 근거 링크를 표시한다. [검색 동작과 한도](../p2-p3-server.md#전사-내용-검색)
- [ ] 전사를 문맥 단위로 나누고 각 검색 구간에 통화 ID, 상대·시각, 전사 구간 ID와 원음 시작·끝을 연결한다. BGE-M3로 임베딩하고, 처음에는 최대 5개 근거를 가져온다.
- [ ] 업무로 지정되고 삭제·만료되지 않은 통화만 검색한다. 상대·기간 조건을 먼저 적용하고, 선택된 구간과 권한을 답변 반환 전에 다시 확인한다.
- [ ] Qwen이 답변과 근거 ID를 구조화해 반환하게 한다. 서버가 이번에 검색한 구간의 ID인지 검증하고 답변 옆에 전사 인용·통화 시각·재생 버튼을 보여준다. 근거 부족·상충은 보류 또는 확인 질문으로 처리한다.
- [ ] 삭제 요청 즉시 검색과 원음 접근을 막고, 관리 중인 전사·검색 구간을 실제로 청소한다. 인덱싱 도중 삭제해도 재노출되지 않는지 검증한다.
- [ ] 후보 확인 화면에서 근거, 제목, 일정의 시작·끝, 할 일의 기한, 승인·거절을 다룬다. 미확정 날짜나 종료 시각은 사용자가 보정하게 한다. 승인과 외부 전송은 별도 상태로 기록한다.
- [ ] 개발 질문 20개를 실행해 근거 검색 누락, 근거는 맞지만 답변 오류, 적절한 보류를 구분한다. 구간 길이·검색 방식·프롬프트 변경은 개발 세트에서만 결정한다.

## 통과 기준

- 단일·다중 통화 질문에서 필요한 근거를 열고 해당 음성 위치로 이동할 수 있다.
- 잘못된 근거 ID, 미분류·사적·삭제된 통화의 노출, 전사에 포함된 지시로 인한 외부 작업은 0건이다.
- 승인·거절·수정 경로를 검증한다. 정보가 부족한 후보와 거절 후보는 외부 등록 대상으로 바뀌지 않는다.
