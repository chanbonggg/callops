# CallOps

갤럭시 통화 녹음을 홈서버에서 안전하게 수집하고, 사용자가 업무 통화로 선택한 녹음만 로컬 AI로 전사·요약하는 개인 자동화 프로젝트입니다.

현재는 **P1~P3 서버 기반, 합성 전사·검색, 일정 후보 검토와 모의 Calendar 전송**을 구현했습니다. 검증에는 합성 WAV와 가짜 결과를 사용했습니다. GPU·실기기·외부 서비스 연동과 운영 배포는 후속 단계입니다. [서버 실행 안내와 검증 범위](docs/p2-p3-server.md)

업무 승인 전 통화 상대·실제 통화 시각 입력과 상대·날짜 검색을 추가했습니다. 데스크톱 준비 전에는 개발용 가상 전사로 서버·웹을 먼저 진행합니다. [전체 진행 체크리스트](docs/progress-checklist.md)를 확인하세요.

합성 전사의 시간 구간을 저장하고 통화 상세에서 버전에 고정된 근거 링크로 조회할 수 있습니다. 기존 가짜 워커가 이 경로를 실행하며 실제 모델 결과 수락은 후속 검증 대상입니다.

통화 목록의 **전사 내용 검색**에서 거래처·기간으로 범위를 좁혀 일치하는 발화와 근거 링크를 볼 수 있습니다. [검색 동작과 한도](docs/p2-p3-server.md#전사-내용-검색)

업무 통화 상세의 **일정 후보 검토**에서 합성 분석이 제안한 일정의 근거를 열고, 제목·한국 시간 기준 시작과 종료를 보정해 승인하거나 거절할 수 있습니다. 승인은 CallOps DB에 저장합니다. [합성 일정 후보 실행 안내](docs/p2-p3-server.md#합성-일정-후보-검토)

통화 목록의 **일정 목록**에서 **새 일정**으로 제목과 시작·종료 시각을 입력하고, 직접 입력한 일정을 수정·삭제할 수 있습니다. 통화에서 승인된 일정은 같은 목록에서 전사 근거를 확인하고 모의 Calendar로 전송할 수 있습니다. [직접 입력 일정 화면](docs/p2-p3-server.md#직접-입력-일정-화면) · [일정 목록과 모의 전송](docs/p2-p3-server.md#승인된-일정과-모의-calendar)

통화 목록의 **할 일 목록**에서 제목만으로 할 일을 추가하고, 한국 시간 기준 기한을 수정하거나 비우고, 완료하거나 삭제할 수 있습니다. [할 일 화면](docs/p2-p3-server.md#직접-입력-할-일-화면) · [할 일 API](docs/p2-p3-server.md#직접-입력-할-일-api)

데스크톱에서는 Whisper GPU 전사와 Qwen3 8B 분석 실험에 성공했고, 저장소의 분석 코드 실행도 사용자가 확인했습니다. 성공한 설정을 옮긴 [AI 전사 모듈과 실행 안내](ai-worker/README.md)를 추가했습니다. 새 전사 모듈의 GPU 재검증·화자 구분·실제 서버 큐 연결은 남아 있습니다.

## 개발 시작

웹 서버는 Starlette로 구성하고 Uvicorn으로 실행합니다. 한 앱 안에서 인증, 통화 관리, 처리 큐를 기능별로 나눕니다. [모듈 구성](docs/01-project.md#3-소유권과-저장소-구성)과 [로컬 HTTPS 실행](docs/p2-p3-server.md#로그인-화면)을 참고하세요.

Python 3.12와 Git이 있는 환경에서 다음 명령으로 하네스를 검증합니다. 추가 패키지는 필요하지 않습니다.

```text
python scripts/check.py
```

이 명령은 저장소 규칙과 하네스 자체를 검사합니다. DB를 포함한 P1 재현은 [P1 실행 안내](docs/p1-foundation.md)를 따릅니다. 단계 테스트가 없거나 DB 환경이 준비되지 않으면 검사는 실패합니다. [에이전트 지침](AGENTS.md)과 [실행·완료 기준](docs/harness.md)을 참고하세요.

## 확정된 원칙

- 갤럭시 원본은 유지한다.
- 홈서버 삭제가 갤럭시 원본 삭제로 전파되지 않게 한다.
- 모든 녹음은 홈서버에 임시 수신하지만, 업무 통화 선택 전에는 Whisper/Ollama 처리를 금지한다.
- 사적 통화는 홈서버 복사본을 삭제한다.
- AI 처리 승인과 일정·할 일의 외부 등록 승인을 분리한다.
- n8n은 CallOps 전용 인스턴스가 아니라 홈서버의 공용 자동화 허브로 운영한다.
- 실제 비밀값, 녹음, 전사문, DB 데이터와 백업은 Git에 저장하지 않는다.
