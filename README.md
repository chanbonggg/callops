# CallOps

갤럭시 통화 녹음을 홈서버에서 안전하게 수집하고, 사용자가 업무 통화로 선택한 녹음만 로컬 AI로 전사·요약하는 개인 자동화 프로젝트입니다.

현재는 **P1~P3 서버 기반, 전사·검색·질문, 일정·할 일 후보 검토, 직접 입력 일정·할 일, 모의 Calendar 양방향 동기화, 30일·90일 만료 정리**를 구현했습니다. D5 로컬 시험에서는 업무 승인된 합성 WAV를 실제 GPU 워커 한 대로 처리해 전사·AI 요약·근거가 붙은 후보를 확인했습니다. 실제 결과를 제출할 워커는 시험 서버에서 명시적으로 지정합니다. [D5 검증](docs/02-desktop.md#2026-11-25-d5-로컬-워커-검증)

홈서버에는 공용 n8n을 설치했고 CallOps 웹의 공개 HTTPS에서 소유자 계정으로 로그인과 로그아웃을 확인했습니다. 홈서버와 GPU 워커의 VPN 연결, 갤럭시 실기기, 실제 Google Calendar, CallOps 알림 연동은 후속 검증입니다. [CallOps 접속](https://callops.finel.co.kr/) · [진행 체크리스트](docs/progress-checklist.md) · [n8n 접속 안내](docs/03-server.md#최초-관리-접속)

업무 승인 전 통화 상대·실제 통화 시각을 입력하고 상대·날짜로 검색할 수 있습니다.

로컬 녹음 수집은 완료 체크섬을 받은 PCM WAV, AAC·ALAC M4A, MP3, AMR-NB·WB를 검사합니다. 실제 갤럭시 전송과 형식별로 서버에서 Whisper까지 이어지는 검증은 후속 단계입니다. [수집 실행과 형식 제한](docs/p2-p3-server.md#수집분류)

통화 상세에서 전사의 시간 구간과 버전에 고정된 근거 링크를 열 수 있습니다. 기본 개발 환경에서는 가짜 워커로, D5 시험 환경에서는 실제 GPU 워커로 같은 저장·조회 경로를 확인합니다. [워커 실행](ai-worker/README.md#d5-워커-실행--wsl-데스크톱)

하단 **전사 검색**의 **키워드 검색**에서 거래처·기간으로 범위를 좁혀 일치하는 발화와 근거 링크를 볼 수 있습니다. **통화에 질문**으로도 전환할 수 있습니다. [검색 동작과 한도](docs/p2-p3-server.md#전사-내용-검색)

업무 통화 상세의 **일정 후보 검토**에서 분석이 제안한 일정의 근거를 열고, 제목·한국 시간 기준 시작과 종료를 보정해 승인하거나 거절할 수 있습니다. 승인은 CallOps DB에 저장합니다. [합성 일정 후보 실행 안내](docs/p2-p3-server.md#합성-일정-후보-검토)

하단 **일정**의 월간 캘린더에서 날짜를 고르면 직접 입력 일정과 통화에서 승인한 일정을 함께 볼 수 있습니다. **새 일정**에서 직접 등록할 수 있고, 일정 카드를 열어 직접 입력 일정을 수정하거나 통화 일정의 전사 근거와 모의 전송 상태를 확인할 수 있습니다. [직접 입력 일정 화면](docs/p2-p3-server.md#직접-입력-일정-화면) · [승인 일정과 모의 전송](docs/p2-p3-server.md#승인된-일정과-모의-calendar)

모의 Calendar에 연결된 통화 일정은 캘린더에서 상세를 열어 현재 일정과 통화 당시 합의를 비교할 수 있습니다. 상세에서 일정을 수정하거나 Google 변경을 가져오고, 양쪽에서 바뀐 경우 적용할 값을 선택합니다. [연결 일정 화면](docs/p2-p3-server.md#연결-일정-웹-화면)

통화 목록의 **할 일 목록**에서 제목만으로 할 일을 추가하고, 한국 시간 기준 기한을 수정하거나 비우고, 완료하거나 삭제할 수 있습니다. [할 일 화면](docs/p2-p3-server.md#직접-입력-할-일-화면) · [할 일 API](docs/p2-p3-server.md#직접-입력-할-일-api)

데스크톱에서는 Whisper `large-v3`의 GPU 전사와 알려진 두 화자의 구간 표시, Qwen3 8B 분석을 로컬에서 시험했습니다. 실제 통화의 화자 전환과 홈서버 VPN 연결은 배포 환경에서 검증합니다. [데스크톱 전사 검증](docs/02-desktop.md#2026-11-23-d3-화자-구분과-전사-재검증) · [AI 실행 안내](ai-worker/README.md)

화자가 표시된 합성 전사의 일정·할 일 후보 추출은 고정 시험 57/57을 통과했습니다. BGE-M3 검색과 Qwen 답변은 기존 최종 20문항의 재평가에서 17/20을 기록했습니다. [D4 추출 결과](docs/02-desktop.md#2026-11-24-d4-추출-고정-평가) · [검색 재평가 결과](docs/02-desktop.md#2026-11-25-d4-검색-재평가)

## 개발 시작

웹 서버는 Starlette로 구성하고 Uvicorn으로 실행합니다. 한 앱 안에서 인증, 통화 관리, 처리 큐를 기능별로 나눕니다. [모듈 구성](docs/01-project.md#3-소유권과-저장소-구성)과 [로컬 HTTPS 실행](docs/p2-p3-server.md#로그인-화면)을 참고하세요.

Python 3.12와 Git이 있는 환경에서 다음 명령으로 하네스를 검증합니다. 이 명령에는 추가 패키지가 필요하지 않습니다. 서버 기능 변경은 [requirements.txt](requirements.txt)를 설치한 뒤 임시 PostgreSQL 검사(`python scripts/test_postgres.py --pg-bin <경로> --phase P3`)로 확인합니다. [검사 안내](docs/harness.md#실행)

```text
python scripts/check.py
```

이 명령은 저장소 규칙과 하네스 자체를 검사합니다. DB를 포함한 P1 재현은 [P1 실행 안내](docs/p1-foundation.md)를 따릅니다. 단계 테스트가 없거나 DB 환경이 준비되지 않으면 검사는 실패합니다. [에이전트 지침](AGENTS.md)과 [실행·완료 기준](docs/harness.md)을 참고하세요.

## 확정된 원칙

- 갤럭시 원본은 유지한다.
- 홈서버 삭제가 갤럭시 원본 삭제로 전파되지 않게 한다.
- 모든 녹음은 홈서버에 임시 수신하지만, 업무 통화 선택 전에는 Whisper/Ollama 처리를 금지한다.
- 사적 통화는 홈서버 복사본을 삭제한다.
- AI 처리 승인과 일정·할 일의 외부 등록 승인을 분리한다.
- n8n은 CallOps 전용 인스턴스가 아니라 홈서버의 공용 자동화 허브로 운영한다.
- 실제 비밀값, 녹음, 전사문, DB 데이터와 백업은 Git에 저장하지 않는다.
