# 데스크톱 AI 모듈

## 책임과 구현 의도

데스크톱에서 로컬 Whisper 전사, Qwen 구조화 분석, BGE-M3 임베딩과 근거 기반 질문 답변을 실행한다. `app/worker.py`는 업무 승인된 STT·ANALYSIS 작업을 API로 가져와 한 번에 한 단계씩 처리한다. [실행 안내](README.md) · [서버 처리 지침](../src/callops/processing/AGENTS.md)

## 실행 흐름

- `app/transcriber.py`는 로컬 모델을 CUDA `int8_float16`, 한국어, beam size 5로 실행한다. VAD와 단어 단위 시간 정렬을 켜고 이전 디코딩 구간의 텍스트는 다음 구간에 전달하지 않는다. CLI 기본값은 D3의 로컬 `large-v3` 모델 경로이며 `--model`로 지정할 수 있다. [실행 안내](README.md#전사-실행--wsl-데스크톱)
- `app/diarization.py`는 화자가 두 명임을 아는 입력에서 sherpa-onnx 구간을 원본 시각으로 반환한다. 전사 구간에 복수 화자가 걸치거나 근거가 부족하면 화자 라벨을 비운다. 화자 정보는 별도 `speaker_turns`와 `segment_speakers`에 기록한다.
- 전사 출력은 같은 디렉터리에서 임시 파일을 fsync한 후 하드 링크로 공개한다. 기존 출력은 덮어쓰지 않고 CLI 오류에는 원문·파일명·디코더 상세를 노출하지 않는다.
- 실제 워커는 음성 감지 구간을 원래 시각의 clip으로 Whisper에 전달한다. 이 경로에서 떨어진 제안·정정·확인 발화를 각각 전사한다.
- 워커는 입력의 artifact ID·버전·SHA-256을 대조하고 heartbeat와 단계 기한을 따로 적용한다. `app/worker_io.py`는 사용자 전용 복사본과 결과 바이트·요청 키를 보관한다. 재시작 때 결과 상태를 조회해 같은 바이트만 재전송하고, 수락·취소 후 복사본 삭제를 확인한다.
- `app/worker_engine.py`는 자기 프로세스 그룹에서 Whisper 또는 전용 루프백 Ollama를 실행한다. 연산 프로세스 환경에는 로컬 실행 경로만 넘긴다. 종료 미확인 표식이 있으면 새 claim을 차단한다. 분석은 서버에서 가져온 고정 전사를 읽고, 취소 발화와 불확실성은 근거와 함께 검토용으로 돌려준다.
- `app/analyzer.py`는 화자·원본 ID·시간이 있는 구간을 루프백의 Ollama에 전달한다. 응답 스키마와 해당 요청의 근거 ID를 검증하고, 인용한 원문 시간 표현을 확인된 통화 시각·시간대로 해석한다. 조각별 근거를 원래 순서로 다시 대조하고 전 구간이 성공한 경우에만 결과를 반환한다.
- 재대조 프롬프트에서 반복된 요약·검토 문맥을 줄이고 후보 근거와 확인 항목의 원본 ID를 보존한다. 정정 또는 별도 일정의 인용을 보정할 때 발화의 표현과 최종 후보를 대조한다.
- `app/evaluate_analysis.py`는 합성 대본을 사용해 후보 수·상태·시각·근거를 대조하고 버전, 실패 위치와 조각별 처리량을 기록한다. 일정 등록과 사용자 승인 상태는 서버가 담당한다.
- `app/rag.py`는 데스크톱 실행과 D4 평가에서 공통으로 쓰는 BGE-M3 임베딩과 `rag-v10` 답변을 담당한다. 모델이 반환한 인용 ID는 제공받은 근거에 대조한다. 초안의 인용이 유효하지 않으면 허용 ID로 한 번 재시도한다. 근거가 비면 Ollama를 시작하지 않고 보류한다.
- `RAG_EMBED`·`RAG_ANSWER`는 `StageProcess`의 버전 1 실행 계약을 사용한다. 호출자는 같은 워커 루트 잠금에서 기한·취소를 적용하고 작업 사본을 정리한다. 서버의 업무 승인·근거 조회·권한 및 만료 확인은 서버 후속 연동에서 적용한다. [질문 모델 실행 계약](README.md#질문-모델-워커-실행)
- `app/evaluate_rag.py`는 합성 개발·최종 질문에서 검색·인용을 평가한다. 개발 보고서의 모델 설정과 공용 RAG 코드 해시로 최종 실행의 동일성을 확인한다. [검색 평가 실행](README.md#d4-검색-평가)

## 변경 시 확인

- WSL 데스크톱에서 검증한 패키지 버전과 모델 캐시 식별값은 [패키지 스냅샷](requirements-d1.txt)과 [D0~D1 기록](../docs/02-desktop.md#2026-11-21-d0d1-검증-기록)을 참고한다.
- 실제 모델 호출을 기본 검사에 넣지 않는다. 모델 캐시·드라이버·패키지·데스크톱 연결 변경은 해당 환경의 실행 계획을 따른다. [데스크톱 계획](../docs/02-desktop.md)
- 루트에서 `python -m unittest discover -s ai-worker/tests -v`로 전사·분석과 입력 불일치, 재시작 후 결과 재조회, 연산 기한·종료 확인을 검사한다. 모의 테스트는 D1 Python 환경에서 실행한다. 실제 GPU와 로컬 HTTPS의 합성 음성 통합 시험은 별도로 실행한다. [워커 모의 테스트](tests/test_worker.py) · [D5 실행](README.md#d5-워커-실행--wsl-데스크톱)
- 질문 모델 변경은 벡터 차원·유한성·정규화, 근거 밖 인용, 컨텍스트 한도, 무근거 보류와 종료 미확인 차단을 검사한다. `app.rag_smoke`는 명시적으로 실행할 때만 합성 질문과 근거로 실제 GPU를 사용한다. [질문 워커 검사](tests/test_rag_worker.py) · [합성 GPU 시험](README.md#wsl-gpu-합성-시험)
